🔧 ツール連携の理解

🎯 学習目標 MCP (Model Context Protocol) を通じたツール連携の仕組みを理解し、実際の Jira 操作を体験します。

📚 MCP とは？

Model Context Protocol (MCP) の概要

MCP は AI エージェントが外部のツールやサービスと安全に連携するためのプロトコルです。

  • 統一されたインターフェース - 異なるサービスを同じ方法で操作
  • セキュリティ - 認証とアクセス制御の一元管理
  • 拡張性 - 新しいツールを簡単に追加可能
  • リアルタイム - SSE（Server-Sent Events）による即座の応答

🔗 このエージェントの仕組み

1

アーキテクチャの理解

  • 接続フロー
    • ユーザー → ADK Web インターフェース
    • ADK → Jira Remote MCP Agent
    • Agent → MCP Toolset
    • MCP Toolset → Atlassian MCP Server
    • Atlassian MCP Server → Jira Cloud API

🔒 セキュリティと権限

🛡️ セキュリティモデル
  • API Token ベース認証 - あなたの Jira アカウントの権限で動作
  • 権限の継承 - エージェントはあなたができることのみ実行可能
  • 監査ログ - すべての操作は Jira の活動ログに記録
  • 透明性 - エージェントが実行する操作は事前に説明

📊 パフォーマンスの考慮事項

レスポンス時間について ▼
  • ネットワーク遅延 - リモート MCP サーバーとの通信時間
  • Jira API 応答時間 - クエリの複雑さに依存
  • データ量 - 大きな結果セットは処理に時間がかかる
  • レート制限 - Atlassian API の利用制限

🚨 よくある問題と解決方法

認証エラー (401 Unauthorized) ▼
🔍 症状: "Authentication failed" や "401 Unauthorized" エラー

チェック項目:

  1. API Token の確認
    # .env ファイルの確認（Token は表示されません） grep -v API_TOKEN .env
  2. メールアドレスの確認

    Jira にログインする際のメールアドレスと一致しているか確認

  3. API Token の有効性確認

    curl コマンドで直接テスト:

    curl -u "your-email@example.com:YOUR_API_TOKEN" \ "https://your-domain.atlassian.net/rest/api/3/myself"

解決方法:

  • 新しい API Token を作成して置き換える
  • .env ファイルの設定値を再確認
  • スペースや改行文字が入っていないか確認
サーバー起動エラー ▼
🔍 症状: "adk web" コマンドが失敗する

チェック項目:

  1. 仮想環境の確認
    # 仮想環境がアクティブか確認 which python # 期待する結果: .venv/bin/python のパスが表示される
  2. 依存関係の確認
    # ADK がインストールされているか確認 pip show google-adk
  3. ポートの確認
    # ポート 8000 が使用されているか確認 lsof -i :8000

解決方法:

  • 仮想環境を再アクティベート: source .venv/bin/activate
  • 依存関係を再インストール: uv sync --all-extras
  • 別のポートを使用: adk web --port 8001 jira_remote_mcp_apikey_agent/
接続タイムアウトエラー ▼
🔍 症状: "Connection timeout" や "Request timeout" エラー

解決方法:

  1. タイムアウト設定の調整

    .env ファイルに以下を追加:

    JIRA_CONNECTION_TIMEOUT=60
  2. ネットワーク接続の確認
    # MCP サーバーへの接続確認 curl -I https://mcp.atlassian.com/v1/sse
  3. プロキシ設定の確認

    企業ネットワークの場合、プロキシ設定が必要な場合があります

権限エラー (403 Forbidden) ▼
🔍 症状: "403 Forbidden" や "Permission denied" エラー

原因と解決方法:

  • Jira の権限不足 - 管理者に権限の確認を依頼
  • プロジェクトへのアクセス権なし - 適切なプロジェクトでテスト
  • API Token の権限制限 - アカウントの権限設定を確認
# 自分の権限を確認 curl -u "your-email:token" \ "https://your-domain.atlassian.net/rest/api/3/mypermissions"
