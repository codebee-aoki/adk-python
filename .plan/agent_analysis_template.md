# エージェント分析テンプレート

このテンプレートは、各エージェントの技術ドキュメント作成時に使用する標準的な分析フレームワークです。

## 分析チェックリスト

### 1. 基本情報収集
- [ ] エージェント名と説明
- [ ] 使用しているモデル
- [ ] 主要な機能と目的
- [ ] 対象ユースケース

### 2. ファイル構造分析
- [ ] agent.py の構造
- [ ] main.py の有無と役割
- [ ] 追加ファイル (tools.py, config files, etc.)
- [ ] README.md の内容
- [ ] サンプルファイル (input.json, output files, etc.)

### 3. コードアーキテクチャ解析
- [ ] 使用している ADK コンポーネント
  - [ ] Agent/LlmAgent/SequentialAgent
  - [ ] 使用しているツール
  - [ ] コールバック機能
  - [ ] プランナー設定
- [ ] インポート文とライブラリ依存関係
- [ ] カスタムツール実装
- [ ] 認証メカニズム
- [ ] 設定パラメータ

### 4. 技術パターン特定
- [ ] 使用している設計パターン
- [ ] 状態管理方法
- [ ] エラーハンドリング
- [ ] 外部サービス統合方法
- [ ] データフロー

### 5. 設定・環境要件
- [ ] 必要な環境変数
- [ ] 外部サービスの設定
- [ ] 認証情報の設定
- [ ] 依存関係とインストール要件

### 6. 実行方法
- [ ] 基本的な実行方法
- [ ] CLI での実行
- [ ] Web UI での使用
- [ ] 入力パラメータ

### 7. 特徴的な実装詳細
- [ ] 独特な実装パターン

## ドキュメント品質チェック

### 完成度チェック
- [ ] 概要が明確に記載されている
