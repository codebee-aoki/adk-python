# シンプルなLive（双方向ストリーミング）Agent
このプロジェクトは、テストと実験用に設計されたライブ双方向ストリーミングagentの基本的な例を提供します。

完全なドキュメントは[こちら](https://google.github.io/adk-docs/streaming/)で確認できます。

## はじめに

agentを起動して実行するには、以下の手順に従ってください：

1.  **ADK Webサーバーの起動**
    ターミナルを開き、`live_bidi_streaming_agent`フォルダーが含まれるルートディレクトリに移動して、以下のコマンドを実行します：
    ```bash
    adk web
    ```

2.  **ADK Web UIへのアクセス**
    サーバーが実行されたら、Webブラウザーを開いて、ターミナルに表示されたURL（通常は`http://localhost:8000`）に移動します。

3.  **Agentの選択**
    ADK Web UIの左上角で、ドロップダウンメニューを使用してこのagentを選択します。

4.  **ストリーミングを開始**
    チャット入力ボックスの近くにある**Audio**または**Video**アイコンをクリックして、ストリーミングセッションを開始します。

5.  **Agentとの対話**
    これでagentと話し始めることができ、リアルタイムで応答します。

## 使用上の注意

* ストリームを開始するには、**Audio**または**Video**ボタンを一度クリックするだけで済みます。現在のバージョンでは、セッション中にボタンを再度クリックしてストリームを停止および再開することはサポートされていません。
