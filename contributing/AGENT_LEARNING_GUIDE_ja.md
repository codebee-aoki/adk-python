# ADK エージェント学習ガイド

## 概要

このガイドは、ADK (Agent Development Kit) の `contributing/samples` ディレクトリにある42のサンプルエージェントを効率的に学習するための包括的なロードマップです。各エージェントは特定の概念や技術を学ぶために設計されており、段階的に学習することでADKの全機能を習得できます。

## 学習目標

このガイドを完了することで、以下の能力を身につけることができます：

- **基礎技術**: カスタムツール開発、エージェント設定、状態管理
- **統合技術**: 外部サービス連携、認証システム、ワークフロー設計
- **高度技術**: プロトコル統合、リアルタイム処理、複雑な状態管理
- **専門技術**: フレームワーク統合、特殊用途システム、エンタープライズ統合

## 前提知識

### 必須知識
- **Python**: 中級レベル（非同期処理、型ヒント、デコレータ）
- **API**: REST API の基本概念
- **JSON**: データ形式の理解
- **環境変数**: 設定管理の基本

### 推奨知識
- **Google Cloud Platform**: サービス概要
- **OAuth2**: 認証フローの理解
- **Docker**: コンテナ技術の基本
- **Git**: バージョン管理システム

## 学習パス設計

学習者のレベルと目標に応じて、4つの学習パスを提供します：

### 🟢 基礎パス（初心者向け）

## よくある質問

### Q: どの学習パスから始めるべきですか？
A: Python と API の基本知識がある場合は基礎パスから始めてください。既に類似のフレームワーク経験がある場合は統合パスから開始することも可能です。

### Q: 各パスにどのくらい時間がかかりますか？
A: 個人の経験レベルによりますが、基礎パス（2-3週間）、統合パス（3-4週間）、高度パス（4-5週間）、専門パス（2-3週間）が目安です。

### Q: 実際のプロジェクトで使用する場合の注意点は？
A: セキュリティ、スケーラビリティ、コスト管理、エラーハンドリングを十分に検討してください。サンプルコードは学習用であり、本番環境での使用前に適切な検証が必要です。
