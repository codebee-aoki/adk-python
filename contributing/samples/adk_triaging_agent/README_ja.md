# ADK Issue Triaging Assistant

ADK Issue Triaging Assistantは、`google/adk-python`リポジトリのGitHub issueを管理およびトリアージするために設計されたPythonベースのagentです。大規模言語モデルを使用して新しいissueやラベルが付いていないissueを分析し、事前定義されたルールセットに基づいて適切なラベルを推奨し、適用します。

このagentは、ローカル使用のための対話型モードまたは完全に自動化されたGitHub Actionsワークフローという2つの異なるモードで動作できます。

---

## 対話型モード

このモードでは、agentをローカルで実行して、リポジトリのissueに変更を加える前にリアルタイムで推奨事項を確認できます。

### 機能
* **Webインターフェース**: agentの対話型モードは、ADKの`adk web`コマンドを使用してWebブラウザでレンダリングできます。
* **ユーザー承認**: 対話型モードでは、agentはGitHub issueにラベルを適用する前に確認を求めるように指示されます。

### 対話型モードでの実行
対話型モードでagentを実行するには、まず必要な環境変数を設定します。次に、ターミナルで以下のコマンドを実行します：

```bash
adk web
```
これによりローカルサーバーが起動し、ブラウザでagentのWebインターフェースにアクセスするためのURLが提供されます。

---

## GitHub ワークフローモード

自動化されたハンズフリのissueトリアージのために、agentはGitHub Actionsワークフローを使用してリポジトリのCI/CDパイプラインに直接統合できます。

### ワークフローのトリガー
GitHubワークフローは、特定のトリガーで実行されるように設定されています：

1.  **Issueイベント**: 新しいissueが`opened`されたとき、または既存のissueが`reopened`されたときに、ワークフローが自動的に実行されます。

2.  **スケジュールされた実行**: ワークフローは定期的なスケジュール（6時間ごと）でも実行され、見逃された可能性のあるラベルなしのissueを処理します。

### 自動ラベリング
GitHubワークフローの一部として実行される場合、agentは非対話型で動作します。最適なラベルを特定し、ユーザーの承認を必要とせずに直接適用します。この動作は、ワークフローファイルで`INTERACTIVE`環境変数を`0`に設定することで構成されます。

### ワークフローの設定
ワークフローはYAMLファイル（`.github/workflows/triage.yml`）で定義されています。このファイルには、コードのチェックアウト、Python環境のセットアップ、依存関係のインストール、必要な環境変数とシークレットを使用したトリアージスクリプトの実行ステップが含まれています。

---

## セットアップと設定

対話型モードまたはワークフローモードのいずれで実行する場合でも、agentには以下のセットアップが必要です。

### 依存関係
agentには以下のPythonライブラリが必要です。

```bash
pip install --upgrade pip
pip install google-adk requests
```

### 環境変数
agentが必要なサービスに接続するために、以下の環境変数が必要です。

* `GITHUB_TOKEN`: **（必須）** `issues:write`権限を持つGitHub Personal Access Token。対話型モードとワークフローモードの両方で必要です。
* `GOOGLE_API_KEY`: **（必須）** Gemini APIのAPIキー。対話型モードとワークフローモードの両方で必要です。
* `OWNER`: リポジトリを所有するGitHub組織またはユーザー名（例：`google`）。両方のモードで必要です。
* `REPO`: GitHubリポジトリの名前（例：`adk-python`）。両方のモードで必要です。
* `INTERACTIVE`: agentの対話モードを制御します。自動化されたワークフローの場合、これは`0`に設定されます。対話型モードの場合、`1`に設定するか、未設定のままにする必要があります。

対話型モードでのローカル実行の場合、これらの変数をプロジェクトのルートディレクトリの`.env`ファイルに配置できます。GitHubワークフローの場合、リポジトリシークレットとして設定する必要があります。
